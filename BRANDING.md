# Branding and distribution notes

Project: **Kartikay Imaging Toolkit**

Project lead and maintainer: **Kartikay Srivastava**

Branding revision: 2026-11-08.

This distribution changes project presentation, documentation, citation metadata,
Zenodo metadata, and documentation publisher identifiers. The base algorithms,
namespace, target names, filenames, third-party sources, and dependency download
locations are preserved for compatibility. Original logos remain as historical
assets but are replaced by Kartikay branding on the main documentation surfaces.

Public badges, sponsorship claims, professional-service promotion, upstream edit
links, and automatic upstream dashboard submission settings are removed from the
main project surfaces. No new repository URL, domain, email, DOI, release version,
or ownership transfer has been invented. The original archive revision is recorded
in CONTRIBUTORS.md; the supplied archive itself is unchanged.

Original names remain in contributor credits, scientific citations, copyright and
license notices, technical references, historical releases, dependency endpoints,
and development tools where removing them could erase attribution or break use.
LICENSE, NOTICE, source copyright headers, and third-party license files are retained.

This rebranding identifies Kartikay Srivastava as the lead of this distribution;
it does not assert that he wrote the pre-existing ITK algorithms.
