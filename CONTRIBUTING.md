# Contribute to Kartikay Imaging Toolkit

Kartikay Srivastava maintains this distribution. Submit proposed changes through
the repository hosting this copy once it is configured. Include the problem,
your change, and relevant build or test results.

Preserve API compatibility, contributor credits, copyright headers, and licenses.
Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). New contributors should add their
credit to [CONTRIBUTORS.md](CONTRIBUTORS.md).

No repository URL or contact address has been assigned to this distribution yet.
