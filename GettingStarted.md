# Getting started with Kartikay Imaging Toolkit

**Project lead and maintainer: Kartikay Srivastava**

1. Build the source using the commands in [README.md](README.md).
2. Enable `BUILD_EXAMPLES=ON` to build the examples under `Examples/`.
3. Use `find_package(ITK REQUIRED)` in CMake and `import itk` with a built
   Python wrapping environment. API names remain compatible with the base toolkit.
4. Read the [local documentation](Documentation/docs/index.md) and
   [contribution guide](CONTRIBUTING.md).

See [CONTRIBUTORS.md](CONTRIBUTORS.md) for upstream learning resources and credits.
